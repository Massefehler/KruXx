Navigation:
- Keeps the same main navigation throughout home and search, including Playlists and Downloads; search sources and result categories have their own filter row
- Removes the inactive Featured and Podcasts search tabs
- Adds tappable left and right arrows to overflowing filter rows across library, downloads, search, history and statistics; arrows adapt to screen width and font size
- Keeps selected filters visible and reserves space correctly when navigation is placed on the right
- Tapping the app icon or KruXx wordmark returns to the home page from any screen with the shared header

Downloads:
- A short tap on a track's download icon removes all internal original-audio, MP3 and video variants and cancels pending work; deletion failures remain visible for retry
- A long press opens the format and storage choices even when a default has been remembered
- Public folder copies remain separately removable in Downloads
- Applies Artist - Title naming to every download route, including single tracks and bulk actions, instead of using the uploader as the artist when the source title identifies the artist
- Uses the corrected artist and title in download labels, filenames, playback from Downloads and MP3 tags; reusing an older internal MP3 updates KruXx's tags without re-encoding the audio
- Preserves additional title parts and stored source metadata when downloading or copying a track again

Android support:
- Requires Android 7.0 (API 24) or newer, with the same package and release signing certificate for updates that retain app data
